# My Little Hamster 🐹

เกมเลี้ยงแฮมสเตอร์ไอแจ้นซีเรียน 2 ตัว (หมูจิ๋ว / หมูใหญ่) เล่นบนเบราว์เซอร์ ไฟล์เดียว ไม่ต้องมี Backend

## ขึ้น GitHub Pages
1. สร้าง repository ใหม่ (Public) แล้วอัปโหลด `index.html` และ `README.md` ไว้ที่ root
2. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## เลี้ยงด้วยกันแบบเรียลไทม์ (2 คน)
- เมนู **🔄 สลับ** → คนแรกกด **สร้างห้อง** ได้รหัส 4 หลัก (เป็นเจ้าของห้อง)
- คนที่สองใส่รหัสแล้วกด **เข้าห้อง**
- เจ้าของห้องเป็นตัวจริงของเกม: **ข้อมูลของเจ้าของห้อง (เหรียญ คลัง ตัวละคร กรง) จะไปทับข้อมูลของคนเข้าห้อง** และถูกบันทึกในเครื่องของเขาด้วย
- ทั้งสองคนทำได้ทุกอย่างกับทั้งสองกรง: ให้อาหาร ลูบ วิ่งจักร ขุด ทำความสะอาด ตกแต่ง ซื้อของ และเห็นแฮมสเตอร์ขยับตรงกัน
- ใช้ PeerJS (WebRTC P2P ผ่านโบรกเกอร์สาธารณะของ PeerJS) บางเครือข่ายอาจเชื่อมต่อไม่ได้ เพราะไม่มี TURN server
- โหมดเดี่ยวเล่นออฟไลน์ได้ตามปกติ

## การสัมผัส
แตะ **หัว / แก้ม / จมูก / หู / อุ้งเท้า / ตัว** · **ลากนิ้วลูบ** · **แตะสองที** · กดค้างตอนอมอาหารแล้วลากซ้าย-ขวา (มินิเกมคายอาหาร)
- อารมณ์ที่แสดงออก 3,600 แบบ (ท่าทาง × หู × ตา × ปาก/หนวด/จมูก)
- คำพูด 1,016 แบบ รวมถึงขอขนม/อาหาร ถามหาพ่อกับแม่ และขอของเล่น

## ท่าพิเศษ (ปลดล็อกตามความไว้ใจ)
ยืนสองขา (40) · ตีลังกา (50) · เต้นส่ายตัว (60) · นอนหงายท้อง (75) · ท่าหัวใจ (85)

## ของตกแต่งกรง
ช่องพื้น 4 ช่อง + ช่องผนัง 4 ช่อง มีของตกแต่ง 19 ชิ้น (อุโมงค์ อ่างทราย ของเล่น ท่อนไม้ เห็ด ดอกไม้ เต็นท์ ปราสาท นาฬิกา ดาว พระจันทร์ เมฆ กระดิ่ง ลูกโป่ง รุ้ง ฯลฯ) และวัสดุปูพื้น 6 สี

## หมายเหตุ
มินิเกมคายอาหารเป็นการเล่นสมมติ ในชีวิตจริงห้ามเขย่าหรือบีบแก้มแฮมสเตอร์ และควรเลี้ยงซีเรียนแยกกรง
