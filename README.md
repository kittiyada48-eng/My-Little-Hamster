# My Little Hamster 🐹

เกมเลี้ยงแฮมสเตอร์ไอแจ้นซีเรียน 2 ตัว (หมูจิ๋ว / หมูใหญ่) เล่นบนเบราว์เซอร์ ไฟล์เดียว ไม่ต้องมี Backend

## ขึ้น GitHub Pages
1. สร้าง repository ใหม่ (Public) แล้วอัปโหลด `index.html` และ `README.md` ไว้ที่ root
2. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## เลี้ยงด้วยกัน 2 คน (เมนู 🔄 สลับ)
**แบบห้อง:** คนแรกกด *สร้างห้อง* ได้รหัส 4 หลัก → คนที่สองใส่รหัสแล้วกด *เข้าห้อง*
- เจ้าของห้องเป็นตัวจริงของเกม ข้อมูลของเขาจะทับข้อมูลคนเข้าห้อง ทั้งสองคนทำได้ทุกอย่างกับทั้งสองกรง
- เจ้าของห้องต้อง **เปิดหน้าเกมค้างไว้** อย่าสลับแอป (เกมขอ Wake Lock และต่อห้องใหม่อัตโนมัติถ้าหลุด)
- ใช้ PeerJS + STUN หลายตัว + TURN สาธารณะของ Open Relay (ฟรี อาจไม่เสถียร)

**เข้าห้องไม่ได้? ใช้โหมดโค้ด** (ไม่ผ่านเซิร์ฟเวอร์ห้องเลย)
1. เจ้าของห้องกด *สร้างโค้ดเชิญ* → คัดลอกส่งให้เพื่อน (LINE/แชทอะไรก็ได้)
2. เพื่อนวางโค้ดช่องล่าง กด *วางโค้ดเชิญ → สร้างโค้ดตอบกลับ* → คัดลอกส่งกลับ
3. เจ้าของห้องวางโค้ดตอบกลับ กด *เชื่อมต่อ*

ถ้ายังต่อไม่ได้ทั้งสองแบบ มักเป็นเพราะเครือข่าย (มือถือบางเจ้า/ไฟร์วอลล์) ลองเปลี่ยนเน็ตฝั่งใดฝั่งหนึ่ง เช่นเปลี่ยนเป็น Wi-Fi

## ทำความสะอาดกรง 3 ขั้น
1. **ถูหน้าจอ** — ใช้นิ้วถูคราบสกปรกให้สะอาด
2. **เก็บรองกรงเก่า** — ปัด/แตะกองรองพื้นเก่าออก (อาจเจออาหารที่แฮมสเตอร์ซ่อนไว้)
3. **เทรองกรงใหม่** — เลือกสีวัสดุ แล้วลากนิ้วเทตามใจ เทหนา/บางได้ ออกแบบลายพื้นเองได้ (บันทึกและโชว์ในกรง)

## เกมหาเหรียญ
แตะเหรียญ 🪙 (และเพชร 💎) ให้ทันใน 30 วินาที ได้เหรียญสูงสุด 30 เหรียญ พักเกม 1 นาที

## สวนผัก 🌱
ปลูกเมล็ดทานตะวัน ฟักทอง ธัญพืช บรอกโคลี แครอต แตงกวา ถั่วลิสง → รดน้ำ (ทุก 10 วิ ช่วยให้โตไว) → เก็บเกี่ยวเป็นอาหารเข้าคลัง ต้นโตต่อแม้ปิดเกม

## อื่น ๆ
การสัมผัส 6 จุด + ลูบ + แตะสองที · อารมณ์ 3,600 แบบ · คำพูด 1,016 แบบ · ท่าพิเศษ 5 ท่า · ของตกแต่ง 19 ชิ้น

มินิเกมคายอาหารเป็นการเล่นสมมติ ในชีวิตจริงห้ามเขย่าหรือบีบแก้มแฮมสเตอร์ และควรเลี้ยงซีเรียนแยกกรง
