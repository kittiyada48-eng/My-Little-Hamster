# My Little Hamster 🐹

เกมเลี้ยงแฮมสเตอร์ไอแจ้นซีเรียน 2 ตัว (หมูจิ๋ว / หมูใหญ่) เล่นบนเบราว์เซอร์ ไฟล์เดียว ไม่ต้องมี Backend

## ขึ้น GitHub Pages
1. สร้าง repository ใหม่ (Public) แล้วอัปโหลด `index.html` และ `README.md` ไว้ที่ root
2. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
3. เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/` หลังรอ 1–2 นาที

## เลี้ยงด้วยกัน (พ่อ 👨 + แม่ 👩) — เมนู 🔄 สลับ
- **เลือกก่อนเข้าห้องว่าคุณคือ พ่อ หรือ แม่** (จำไว้ในเครื่อง) ถ้าสองคนเลือกซ้ำกัน คนเข้าห้องจะถูกสลับเป็นอีกบทบาทอัตโนมัติ
- คนสร้างห้องเป็นตัวจริงของเกม ข้อมูลทับฝั่งคนเข้าห้อง · ทั้งคู่ดูแลหนูทั้ง 2 ตัวได้เต็มที่
- แถบบนจอบอกว่า พ่อ/แม่ กำลังดูกรงไหน ทำอะไรอยู่ และทุกการกระทำกับหนูจะเด้งแจ้งอีกฝ่าย
- **แท็บ 📜 ประวัติ** แสดงว่าพ่อหรือแม่ทำอะไรให้หนูบ้าง (เวลา, จำนวนครั้งของแต่ละคน, กรองดูเฉพาะพ่อ/แม่ได้) เก็บถาวรและซิงก์ให้ทั้งสองฝั่ง ใช้ในโหมดเล่นคนเดียวได้เช่นกัน
- เข้าห้องไม่ได้ → ใช้ **โหมดโค้ด** (คัดลอกโค้ดส่งหากัน ไม่ผ่านเซิร์ฟเวอร์) · เจ้าของห้องต้องเปิดหน้าเกมค้างไว้

แตะ หัว/แก้ม/จมูก/หู/อุ้งเท้า/ตัว · ลากลูบ · แตะสองที · **จี้ถี่ ๆ** · **กดค้างลูบ** · **กดค้างแล้วลากเพื่ออุ้ม** · **แตะพื้นกรงเรียกให้เดินมาหา** · ตาตามนิ้ว · มีเสียง/สั่นเบา ๆ (ปิดเสียงได้ที่หน้าบ้าน) · ถ้าจี้ถี่เกินไปจะหงุดหงิด
อารมณ์ 3,600+ แบบ · คำพูด 1,016 แบบ (ขอขนม ถามหาพ่อแม่ ขอของเล่น)

## จัดกรง
- แท็บ 🛋️ ตกแต่ง → วางของ แล้วกด **✋ จัดวางของเอง** ลากย้ายได้ทุกที่ (พื้น 6 ช่อง ผนัง 6 ช่อง)
- **แฮมสเตอร์นอนใต้รองกรง**: เมื่อกรงมีรองพื้นพอ เจ้าตัวจะขุดลงไปนอน เหลือแต่ปลายหู ต้อง **ลากนิ้วซ้าย-ขวาบนกองรองพื้น** เพื่อปลุก
- ทำความสะอาดกรง 3 ขั้น: ถูหน้าจอ → ปัดเก็บรองกรงเก่า → เทรองกรงใหม่ตามแบบที่ออกแบบเอง (รองพื้นจะไม่ทับถ้วยข้าว)

## หาเงิน 🪙
- **เกม 24**: ใช้เลข 4 ตัว (1–9) กับ + − × ÷ ให้ได้ 24 · ถูก +5 เหรียญ (ตอบเร็วได้โบนัส) · มีปุ่มย้อน/เฉลย
- เกมหาเหรียญ (แตะเหรียญใน 30 วิ) · สวนผัก 🌱 ปลูก-รดน้ำ-เก็บเกี่ยวเป็นอาหาร

มินิเกมคายอาหารและการอุ้มเป็นการเล่นสมมติ ในชีวิตจริงห้ามเขย่า/บีบแก้มแฮมสเตอร์ และควรเลี้ยงซีเรียนแยกกรง
